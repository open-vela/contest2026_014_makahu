# 手机端 LLM 服务

更新时间：2026-09-20

## 配置

设置 → LLM 服务：填写 Base URL、模型名称和 API Key。Base URL 可为服务根路径、含 /v1 的路径或完整 /chat/completions 路径。统一发送 Chat Completions 请求：model、messages、stream=false；有密钥时使用 Bearer 鉴权。未依赖服务商特定 JSON 模式，使用提示约束 JSON 并在手机端校验结果。

API Key 经 Android Keystore AES-GCM 加密保存在手机私有设置中，不写入事件、不下发到 Vela，不展示服务错误响应正文。配置可以单独测试连接和移除。

## 职责

手机调用兼容接口完成分类提案、问题回答和周总结。不要求模型权重在手机本地运行。分类仍需用户确认；回答不可靠时保留未解状态。日历、健康写入仍走原有确认流程，模型不会直接执行系统操作。

Coordinator 的产品规则已明确为自动推选“手机 > Vela”。本轮 LLM 接入不代表分布式 Coordinator 选举、离线接替和恢复抢占已经实现；它们仍是独立待完成工作。

## 周总结

- 手动与周日定时入口只创建持久化生成任务，不再拼接统计模板生成总结卡。
- 输入为过去七天的记录及事实统计，排除待转写语音和已有周总结。最多提供100条记录，长内容截断并带上遗漏数量。
- 后台在事务外调用服务，使用持久化租约和失败重试。结果校验通过后才保存 WeeklySummaryGenerated 事件与模型正文；过期租约、重复响应不能覆盖结果。
- 没有配置服务、请求失败或模型输出无效时显示待生成/失败状态，不生成规则版替代总结。
- 已删除的总结不会因重复回包或同周自动调度重新出现。

## 收藏与界面

收藏在数据库查询层排除未转写音频，包括被收起后仍未转写的录音。编辑保留原始 Capture；删除移除展示卡，保留原始事件，撤销 Buffer 提醒并移除关联引用。用户编辑和删除事件阻止迟到的分类结果覆盖操作。

收藏使用 Material SwipeToDismissBox：向右编辑、向左打开删除确认。长按进入多选，顶部提供单项编辑和批量删除；有无障碍替代动作。七天回顾使用独立页面、Material 列表与展开分区，LLM 正文优先显示。

## 验证

构建、Lint通过。253项单元测试通过，包含OpenAI-compatible HTTP请求、重定向拒绝、不完整响应拒绝、周总结持久化与租约、失败回滚、删除防复活、收藏筛选、编辑冲突和批量删除。

已安装到 Windows Android 17 模拟器并确认新的 LLM 设置页显示。接口测试使用本地测试服务器，尚未使用用户的真实模型服务验证推理质量。侧滑和多选仍需完整设备交互验收，不能把单元测试当作手势或全部屏幕验收。
