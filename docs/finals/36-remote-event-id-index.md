# 远端事件 ID 索引与分批迁移

日期：2026-10-24。任务 05 的索引子阶段，仅修改与静态回顾源码、文档；没有运行测试、构建、语法检查或设备。承接 [35 远端接收存储](35-vela-remote-event-store.md)，修复其每条新 ID 都重扫历史的问题。网络协议和投影器仍未接通。

## 已修复的问题

35 阶段的独立 ID 文件只能证明一个 ID 存在，缺失时不能区分“从未出现”和“索引文件丢失”。因此每个正常的新事件都会扫描所有已提交原文，批量导入的总成本随历史累积增长。

新增 `buffer_source_index.c/.h`，使用 event_id 的 SHA-256 作为键建立压缩十六进制前缀树。叶保存完整 event_id、source、sequence 与原文指纹；分支保存公共前缀和 16 个子项，每个非空子项同时保存目标前缀和目标节点原文字节的 SHA-256。节点文件的路径只取验证过的前缀，不能由 payload 指定。

查找沿键的前缀读取节点，逐次验证父项中保存的子项指纹。只有已验证节点的空子项或不同前缀才构成不存在的证明。被引用节点丢失、内容不符、非法子项、非递增前缀或损坏结构均报错，不能将损坏树当作新 ID 的空位。叶命中后，接收层仍核对源 head、原文指纹和精确原文；索引不替代事实源。

索引尚未覆盖历史时，`get` 返回 EAGAIN，不提供“未找到”的结果。完成后的叶数与所有独立来源绑定记录中的已接受序号总和比较；索引回退或漏提交不能以旧 ready 标记掩盖。

## 节点与提交

索引保存在 `event-journal/remote-index/`：

| 文件 | 内容 |
| --- | --- |
| `index.json` | 版本、ready、事件数与根引用 |
| `n-<prefix>.json` | 一个叶或压缩分支，最多 4096 字节；空前缀也有固定文件名 |
| `pending.json` | 索引事务的 before/after 元数据和全部节点 afterimage |
| `build.json` | 旧历史迁移的来源哈希、序号和期望事件总数 |

一次插入只修改查找路径并新增叶或分支，不为全部历史重建树。节点以逻辑前缀命名；修改祖先时替换同一文件，新分支保留旧节点作为子项。不会为每次根修订永久保留整套旧节点。已提交图中每个分支至少有两个子项，因此 N 条事件最多有 N 个叶与 N−1 个分支。

键只有 64 个十六进制位，路径最多 65 个节点；单次 afterimage 数也限制为 65。节点最多 4096 字节，事务文件限制为 1 MiB。递归帧只保存固定大小前缀和指针，节点及事务树在堆上分配。数字边界、分配失败和原文超限均返回错误；同 ID 同条目重试不增加事件数，其他条目重用身份拒绝。

在修改任何节点前，先持久保存索引事务；随后写节点，最后替换根元数据，再删除事务。恢复只接受当前元数据恰好等于 before 或 after，校验所有 afterimage 的结构、前缀与指纹，再幂等完成写入。恢复尚未结束时，任何下一次索引访问先处理同一事务；remote 锁保证其他接收线程不会读取半更新的节点。索引元数据缺失但已有节点或事务时不会重新宣称空树。

远端接收意图仍在索引事务外层：源原文和指纹写入后，提交索引，再提交待投影项、观察时钟、owner 序号和源 head。如果中断发生在索引已增加而源 head 尚未增加之间，远端意图会恢复同一事件；重复索引 put 不重复计数。仅有旧数据迁移事务时，不会启动业务命令。

## 旧历史迁移

旧 `remote-ids/` 文件保留为兼容资料，不再作为新 ID 是否可用的依据，也不再为新事件逐个写入这种文件。迁移从各来源已经提交的精确原文重建树，原文、指纹、来源和序号逐个校验。

迁移以来源哈希排序，`build.json` 保存来源与已完成序号。先提交索引 put，再推进迁移游标；中断后重做同一条是幂等操作。最后核对完整事件数，才将 ready 提交为 true。迁移中途不会发布空树或部分树的不存在证明。

每次维护最多处理 16 个记录/空来源步骤；待处理原文字节累计达到 2 MiB 后结束该批次。因此处理过的原文字节最多略低于 3 MiB，另外还存在来源 head 和索引节点的固定有界读取；这些是源码中的工作量边界，不是已测得的耗时或 I/O 性能承诺。

未完成时进度查询和接收入口返回 EAGAIN，本次输入没有被接受，也没有成功存储回执。应用消息 worker 后续重试会继续同一持久游标，不从头重扫。迁移期间不允许新的远端事实改变目标集；目标计数变化、坏游标或历史缺失均报错。本机原始捕获和已提交原文读取不要求索引 ready，仍可使用已有观察时钟；它们继续恢复任何已接受的远端接收意图，但不会同步执行整个索引迁移。
