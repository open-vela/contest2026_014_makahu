# Vela 深挖/回答结果显示修复

2026-10-20。

手机数据库与 Windows Vela 已落盘副本核对，同一问题卡片包含 1077 字符、1083 UTF-8 字节的答案；Vela 副本 revision=19。因此本次具体故障发生在显示投影，而不是答案没有同步。

原实现将 answer 拷贝进 buffer_card_s 的 192 字节预览字段，再接在摘要后放入只有数行的首页标签。打开详情也沿用同一份截短字段。research_notes 则完全未参与显示。

修复内容：

- 轻量首页预览优先使用 research_notes，其次 answer，保留 UTF-8 边界。
- 有结果时直接预览结果，不在短标签里把它排在原摘要之后。
- 详情通过稳定 card_id 读取已落盘的完整副本，依次展示深挖、回答及原记录；不扩大所有卡片的常驻内存字段。
- 投影及缓存保留 content_revision，打开详情时或版本变化时读取全文；每 500ms 刷新不重复读文件。
- 已标记 researched 的问题不再显示重复深挖操作。

本次只做针对真实问题的数据核对、必要编译及 Windows 显示检查，不运行额外测试套件，不重新调用 LLM、不修改或删除现有记录。没有完整副本的旧式卡片仍回退到原本预览，不声称可以恢复此前从未收到的全文。
