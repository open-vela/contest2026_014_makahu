# Vela M3E、dp 与图标一致性审核

日期：2026-11-01。覆盖当前 Vela 全部 UI 实现；接续 11、12、13、15、16、18 号文档。18 号文档的双页职责优先于旧文档的“全局录音”描述。手机端本轮核对共用图标、通知图标、尺寸单位及配对进度表达，未把它扩写成手机全部业务流程验收。

## 依据和单位

已重新阅读项目的 M3E 审核、90 场景动效清单、实施记录和页面职责，并核对官方 States、Motion physics、Typography、Layout、Gestures、Buttons 文档正文缓存。图标以 [Material Symbols 官方说明](https://developers.google.com/fonts/docs/material_symbols) 为依据。

- 设计尺寸使用 dp，字号使用 sp；`buffer_ui_units.h` 按显示器逻辑 DPI 做 `round(dp × DPI / 160)` 换算。当前字体缩放为 100%。
- S1 的实际构建配置 `CONFIG_LV_DPI_DEF=130`；48dp→39px，24dp→20px，64dp→52px。逻辑 DPI 来自设备配置，未声称已经测量或校准面板物理 DPI。
- 边距、间隔、圆角、边框、图标显示尺寸、控件最小尺寸、布局断点、空间动效位移、录音取消距离均通过公共换算。文字角色按 sp 创建 FreeType 字体。
- LVGL 的测量结果、触点坐标、draw-buffer stride 和位图采样仍是像素；百分比、时间、颜色、透明度、索引、角度和真实进度保留各自单位，避免二次换算。
- 公共按钮最小触摸范围为 48×48dp；图标视觉尺寸默认 24dp。圆形启动器为 64dp。月历日期保持 48dp 命中区域，矮屏纵向滚动，窄屏横向滚动，各周/星期均可达。

## 图标来源与状态

Vela 共用 17 个固定版本的 Material Symbols Rounded SVG，wght=400、GRAD=0、opsz=24、FILL=0。来源 URL、版本及 SHA-256 记录于 `third_party/material-symbols/sources.json`，Apache-2.0 许可保留。`generate_symbols.py` 校验原始文件并可重复生成 LVGL A8 资源；原 `generate_mic.py` 入口改为生成全套资源，避免覆盖丢失其他图标。

已替换 LVGL 字体符号、字符箭头/方框、手绘日历/书本/勾号。进度圆环、步骤圆点和背景形状属于状态或容器，不作为图标替代物。录音、更多、待办、日历、历史、翻页、日期导航、网络、设置、成功和警告均使用同一家族。

公共图标直接在实际绘制描述符中读取所属控件的有效文字色，覆盖普通、按下、选中、选中后按下、禁用组合；不依赖额外轮询或持有已删除控件的回调。录音图标使用与红色录音状态成对的 on-color。

手机既有 17 个资源均为 Rounded；另补入同版本 info/alarm，替换 8 处 Android 系统通知图标。导航选中态保留原有 Rounded FILL=1 资源。

## R26 真机复核未通过

用户确认历史入口标题与另外两个入口不齐，且屏幕有内容但无法点击。串口运行检查仅记录到首条 Wi-Fi 状态查询，没有菜单心跳回执。启动/刷写成功不能记为交互可用，R26 的 `runtime_ui_verified=false`。

历史页启动器遗漏了图标与文字间距，本轮页面组合验收不充分。后续将三处入口改用同一个 `buffer_ui_launcher_attach` 生产组件，并增加三种入口标题坐标一致性检查。卡死原因仍待真机诊断；R27 加入原子阶段标记和启动后两分钟内的后台停滞/堆栈记录，诊断采集先跳过无线状态查询，不以此宣称已修复卡死。

## 后续诊断与已证实的阻塞路径

R27 真机完成菜单/日历往返，UI 阶段序列持续增长；联网后 Wi-Fi 状态查询正常、NTP 获取 4 个样本。三处启动器已共用生产组件，中文字体检查补充了三列标题纵坐标一致性。上述结果不证明 R26 卡死的唯一原因已经确定。

另发现 `buffer_agent_snapshot` 与配置文件加载/保存共用 `config_lock`，UI 的 OOBE/服务状态刷新会等待 NAND I/O。增加真实配置读取阻塞的并发用例：修改前 UI 快照无法在存储阻塞期间返回（断言失败），修改后立即得到上一份发布状态。R28 将状态发布锁与配置 I/O 锁分开；配置提交串行、版本检查、凭据读写和校验流程保持原语义。回归同时检查新状态发布、验证中标记和错误更新。它修正了一条确定的 UI 阻塞路径，不能据此替代全部真机触摸/长期稳定性验收。

R28 已刷入并通过回读校验（CRC32 `4b599f60`）；AI 状态查询、菜单和日历往返收到正常回执，UI 进度持续增加。实际手指点击及三个入口对齐仍等待用户确认。
